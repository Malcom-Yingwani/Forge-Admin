# Glossary

| Term | Meaning |
|---|---|
| **Heritage** | The public side: heritage-api plus heritage-web. Also short for Heritage Baptist Church |
| **Forge** | The admin side: forge-api plus forge-admin. It owns the data |
| **Outbox** | A database table of pending deliveries, written in the same transaction as the change it describes |
| **Snapshot / Resync** | Sending every item of a type so Heritage's copy matches Forge exactly |
| **Growth Group** | A small home group meeting during the week |
| **Bible Hour** | The Sunday adult teaching hour before morning worship |
| **Elder / Deacon** | Church offices. Shown on the Pastors & Elders page |
| **POPIA** | Protection of Personal Information Act, South Africa's data-privacy law |
| **Expository preaching** | Preaching through a passage or book of the Bible verse by verse, which is why sermons are organised by series and scripture book |
